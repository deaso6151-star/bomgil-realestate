# 봄길부동산 홈페이지 (교육용 가상 자료)

> 이 저장소의 회사·사람·번호·주소·매물·사진은 모두 **AI 활용 교육용 가상 자료**예요. 실제 회사·매물이 아니며, 실제로 연락하거나 찾아갈 수 없어요.

## 파일

- `index.html` — 홈페이지 한 장 (소개 · 매물 카드 · 거래/유형 필터 · 가상 위치 · 문의 안내)
- `images/` — AI가 만든 예시 사진 4장 (실제 매물 사진 아님)

## 보는 법

`index.html`을 더블클릭해 브라우저로 열어요. 별도 설치나 서버가 필요 없어요.

## 지킨 것

- 전화 걸기·메일 보내기 링크, 지도 연결, 문의 전송 기능이 없어요.
- 비밀번호·API 키·개인정보를 넣지 않았어요.
